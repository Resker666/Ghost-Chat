# 实验版发布清单

适用对象为开源实验版本的准备与审阅；发布源码、创建标签/Release、部署聊天服务是分别记录的动作。本文件不创建任何标签或发布，也不表示生产服务已验收。

## 源码实验版本

- [ ] 确定候选提交与实验版名称；当前默认分支不自动等于已发布稳定版。
- [ ] 候选提交对应的 Go、web、E2E、容器 CI 结果均可追溯；不把旧提交通过套用到新修改。
- [ ] CHANGELOG 说明新增项、实际验证、未测平台和已知限制；README 从独立 clone 开始可复现。
- [ ] 核对应用 MIT、运行依赖 ISC/MIT/Go、Vite 注入 helper 的完整原始声明与测试工具 jsQR 的 Apache-2.0 许可证；jsQR 不进入生产 bundle，若分发测试工具/产物也保留其应有声明。
- [ ] 确认无真实邀请、聊天、令牌、秘密、个人路径、原始日志/抓包、截图或本机工具进入源码/产物。
- [ ] SECURITY.md 列出经实际确认的报告渠道及支持范围；模板不索取敏感材料。
- [ ] 设备矩阵分开列出自动化、真机、测试证书与正式 HTTPS 证据，未测项不标为支持。
- [ ] 发布描述明确实验性、无前向保密、不保证物理擦除、可观察元数据与 Web 发布者信任风险。
- [ ] 审阅具体提交、发布内容及许可证后，再由发布者执行所需标签/Release 动作；没有自动部署承诺。

## 目标服务部署

下面只约束真正部署的目标环境，不能把它们当作公开实验源码本身的前置认证：

- [ ] 目标运行产物（原生程序或镜像）按实际模式经过相应会话 E2E，涵盖授权、互聊、销毁、断线、TTL 与重启；正式服务只执行获授权的受限检查，破坏性/短 TTL 全回归放在专用实例。
- [ ] 实际 Nginx/HTTPS/WSS、Origin、安全头、日志、资源/权限及端口暴露验证完成。
- [ ] 实际设备信任证书，PC 与手机通过不同网络完成受控测试；测试 CA 或忽略 TLS 错误的结果单独注明。
- [ ] 完成 SECURITY.md 的目标环境清单，以及适用的运营、支持和独立安全审查安排。

## 发布记录

记录提交、候选/实际版本、CI 链接、产物标识、测试模式、日期、未完成项与发布者判断。不归档会话正文、完整链接、秘密或原始网络记录。版本创建与发布结果只在实际完成后写入，未经独立审计不得使用“已审计安全”描述。
