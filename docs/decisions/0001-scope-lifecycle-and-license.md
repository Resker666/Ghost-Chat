# ADR 0001：阶段范围、生命周期与许可证

日期：2026-10-14。状态：已接受，依据本轮用户确认。

## 决策

按 P0 验证 → P1 可运行双人 E2EE 并记录测试 → P1.5 加固与可部署执行。P2/P3 仅后续研究。本轮使用 MIT 许可证。

任一已鉴权参与者断线即销毁整房，不重连。A/B 令牌均一次性。首次鉴权前允许零人，避免创建响应后尚未连接即销毁。双方必须在创建后 10 分钟内到齐，总 TTL 从创建起 30 分钟；均可配置测试。

B 先解析并清理 fragment，再显式加入，避免仅打开链接就消耗一次性令牌。未鉴权失败不能销毁合法参与者的房间。

## 原因与代价

原总纲同时含“双方离线才销毁”和“断线失效”，与单次令牌/不重连约束需要统一。所选语义减少半开房间和身份恢复复杂度，但网络短暂中断也需要重新创建并分享邀请。

P1 的最小输入校验、Origin、超时、容量和有界队列是安全成立的基础。P1.5 扩充强化与回归，不推迟这些底线。
