# 隐私说明

本项目不要求账号、手机号、邮箱或固定全局身份。正常实现只在浏览器内处理聊天明文和加密秘密，中继仅在内存保存临时房间、令牌验证材料、连接和有界密文队列。

## 服务端可见信息

公网部署通常能看到 IP、房间标识、角色、连接时间、方向、消息长度及流量模式。E2EE 不隐藏这些元数据。应用日志、前置代理、CDN、云平台、诊断转储和备份配置均需独立检查。

默认不记录访问路径/IP/请求正文、原始头、WebSocket 帧、密钥、令牌或完整链接。不得为调试临时打开这类日志。需要运行指标时仅使用经过审查的非敏感汇总计数。

基础防滥用在内存短期保存连接地址的摘要与窗口计数，不写入持久记录，也不将摘要作为稳定身份。摘要不是可靠的 IP 匿名化手段。服务不信任 `X-Forwarded-For` 等地址头；反代后多个用户共享反代地址的预算，需要在容量配置中考虑。

Compose 示例禁用容器日志驱动；Nginx 示例关闭访问日志并将该站点错误日志送入 `/dev/null`。宿主、守护进程、证书工具或其他前置设施仍需按部署环境逐项审查，示例配置不证明实际云平台没有日志。

## 浏览器与分享

聊天、密钥和令牌只存在当前页面内存，不使用 localStorage、sessionStorage、IndexedDB、Cookie、Service Worker 或离线缓存。敏感响应配置 no-store。

邀请 fragment 初始化立即清理，但分享渠道、剪贴板、浏览器扩展、历史内部实现和持有完整链接的人仍可能读取秘密。浏览器无法可靠验证用户是否已删除所有副本。

## 结束之后

断线、销毁、到期和重启后无应用层恢复功能。JavaScript、交换区、内存分配器、崩溃转储和对方设备可能留下副本，不能承诺物理擦除或阻止截图。首版没有前向保密。

## 对外运营

本轮只提供开源单实例自托管原型，不建立公网共享运营平台。实际公开运营需要补充运营主体、使用条款、滥用策略、地区与合法请求处理流程；不得承诺绕过法律义务。
